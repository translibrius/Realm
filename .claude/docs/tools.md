# Recommended CLI Tools

Tools expected on dev machines. Install via your platform's package manager (`winget`, `brew`, `pacman`, etc.).

| Tool | Command | What it does |
|------|---------|-------------|
| **ripgrep** | `rg` | Fast code search, respects `.gitignore` |
| **fd** | `fd` | Modern `find` replacement |
| **fzf** | `fzf` | Fuzzy finder for files, history, pipes |
| **bat** | `bat` | `cat` with syntax highlighting |
| **eza** | `eza` | Modern `ls` with color and git status |
| **jq** | `jq` | JSON processor |
| **delta** | `delta` | Syntax-highlighted git diffs |
| **lazygit** | `lazygit` | Git TUI for staging, branching, rebasing |
| **zoxide** | `z` | Smart `cd` that learns your habits |
| **starship** | (prompt) | Cross-shell prompt with git/language info |
| **hyperfine** | `hyperfine` | CLI benchmarking |
| **tokei** | `tokei` | Code line counter by language |

Both `starship` and `zoxide` need a one-line shell init — see their docs.
